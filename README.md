# 平安建材株式会社 WordPressテーマ

本番サイトで使用している `heiankenzai` テーマのソースです。

- `main`: 本番環境
- `test`: テスト環境

WordPress本体・プラグイン・アップロードファイル・データベースは、このリポジトリの管理対象外です。

## カタログの更新

管理画面の「カタログ」から、次の項目を更新できます。

- カタログ名
- 説明文
- サムネイル（アイキャッチ画像）
- 補足テキスト
- カタログのリンク先
- ボタンの文言と別タブ表示
- 並び順（ページ属性）
